## 검증 중 발견 및 조치

- React hydration이 `load` 이벤트 뒤에 끝나는 경우 Service Worker 등록이 누락되어 Android 오프라인 콜드 실행이 Chrome 기본 오류 화면으로 떨어지는 문제를 발견했다.
- 문서가 이미 로드된 경우 즉시 등록하도록 수정하고 프로덕션에 재배포했다.
- 수정 후 Android에서 Chrome을 강제 종료하고 비행기 모드로 재실행했을 때 TimeFit 오프라인 업무 차단 안내 셸이 standalone 화면으로 노출되는 것을 확인했다.

## 최종 승인 판정

사용자 요청에 따라 실제 iPhone 검증을 iOS Simulator 검증으로 대체했다. Android Emulator와 iPadOS Simulator에서 설치·standalone 실행·종료 후 재실행을 모두 확인했으므로 MOB-02 승인 기준을 충족한 것으로 판정한다.

- 실제 iPhone Safari와 Samsung Internet 검증은 출시 전 추가 호환성 UAT 항목으로 유지한다.
- 해당 추가 검증은 MOB-02 완료를 차단하지 않는다.
