# MOB-05 직원 개인 스케줄 조회

## 확정 범위

- 직원 역할의 본인 일정만 조회한다.
- 게시(`published`) 및 승인(`approved`)된 일정만 노출한다.
- 주간 기본 화면, 월간 요약, 날짜 상세를 제공한다.
- 명시적 휴무와 일정 없음, 승인 휴가를 구분한다.
- 사업장 시간대와 마지막 동기화 시각을 표시한다.
- 사용자·사업장·조회 기간별 세션 캐시를 사용한다.
- 첫 조회 오류와 기존 데이터 갱신 오류를 구분한다.

## 서버 보안 계약

클라이언트는 `organization_id`, `from`, `to`만 보낸다. 서버가 `auth.uid()`로 `staff_id`를 확정하며 직원 연결이 없으면 `staff_not_linked`로 거절한다. 다른 직원 ID를 입력하는 계약 자체를 제공하지 않는다.

기존 RPC의 `status <> 'cancelled'` 조건은 초안을 노출할 수 있어 `status = 'published' and approval_status = 'approved'`로 강화했다. 승인 휴가만 동일 응답의 `leaves`에 포함한다.

## 후속 범위

- 일정 변경 전후 비교와 직원 확인 여부
- 푸시 알림과 변경 이력 상세
- 데이터 모델 제약을 해소한 하루 복수 근무
- 반차 시간대와 근무 충돌 정책
