# MOB-04 역할별 화면·권한 적용 구현 기록

## 구현 범위

- 직원, 서브 관리자, 총책임자, 사장 역할 컨텍스트
- 역할별 5개 하단 내비게이션
- 관리자 세부 권한에 따른 직원·스케줄·승인 탭 노출
- 권한 없는 해시 직접 접근 차단 및 안전한 홈 복귀
- 복수 역할 선택과 전환 시 업무 캐시·세션 화면 상태 제거
- 직원 홈과 운영 홈의 후속 기능 연결용 카드
- 정지된 관리자 역할 제거

## 역할별 기본 탭

| 역할 | 탭 |
|---|---|
| 직원 | 홈, 스케줄, 출퇴근, 요청, 전체 |
| 서브 관리자 | 홈, 직원, 스케줄, 승인, 전체 |
| 총책임자 | 운영 홈, 직원, 스케줄, 승인, 전체 |
| 사장 | 운영 홈, 사업장, 승인, 알림, 전체 |

관리자 탭은 역할명만으로 열지 않고 서버가 반환한 권한 코드가 있을 때만 표시한다. 화면에서 숨겨도 보안 경계로 간주하지 않으며 실제 데이터 API가 서버 권한과 범위를 다시 검사해야 한다.

## 의존 사항

- 현재 MOB-03은 레거시 `get-user-context` 계약을 사용한다.
- 복수 사업장, 관리자 전용 계정, 범위 목록, `authorization_version`은 Bootstrap v2 서버 계약 적용 시 확장한다.
- MOB-04는 후속 MOB-05·07·08의 실제 업무 데이터를 선구현하지 않고 권한 기반 앱 셸과 진입점까지만 제공한다.
